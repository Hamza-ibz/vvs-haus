# VVS Haus

VVS Haus is a premium mobile detailing website for a luxury automotive brand. The project is built to feel cinematic, modern, minimalist, and high-end, with a Mercedes-focused visual direction and a dark luxury design system.

The site will be built section by section rather than generated all at once. Each section should be implemented, tested, reviewed, and committed before moving to the next major section.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Lucide React Icons

## Brand Direction

VVS Haus should feel:

- Luxury
- Cinematic
- Mercedes-focused
- Professional
- Clean
- Minimalist
- High-end automotive

Core colors:

- Black: `#050505`
- Charcoal: `#111111`
- White: `#FFFFFF`
- Cyan: `#00D9FF`

Typography:

- Headings: `Orbitron`
- Body: `Inter`

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Lint the project:

```bash
npm run lint
```

Preview the production build:

```bash
npm run preview
```

## Build Approach

This project should be developed in small, reviewable phases:

- Explain architecture decisions before generating code.
- Build one section at a time.
- Test each major section with lint and production build commands.
- Keep the visual language premium, dark, cinematic, and Mercedes-focused.
- Avoid unrelated refactors while building a section.

See `BUILD_PLAN.md` for the phased implementation checklist.
